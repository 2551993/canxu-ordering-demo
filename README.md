# 餐序｜窗口点餐 Demo

根据《中期汇报v3(2)》第 7–9 页制作的网页演示。顾客扫描门店码进入菜单，选餐后模拟支付。服务端分配取餐号并生成同号制作单，商家在工作台查看订单、标记出餐和模拟补打。

顾客端和商家端页头的日夜开关参考 [YipThim123 的 SunMoon 组件](https://github.com/YipThim123/sun_moon_public/blob/develop/src/components/SunMoon.vue)。浏览器会记住所选主题。

## 本机运行

1. Windows 双击 `启动点餐Demo.cmd`，浏览器会打开 [顾客点餐页](http://127.0.0.1:8787/)。使用终端时，在项目文件夹中执行 `npm ci` 和 `npm start`，再打开顾客点餐页。使用 Node.js 22 或更高版本。
2. 在运行 Demo 的电脑上，从顾客页点进「商家入口」，首次填写手机号和密码完成注册。注册成功后进入工作台，退出后使用同一手机号和密码登录。
3. 在「门店设置」填店名、地址和公告，在「菜单管理」添加分类与餐品，填写价格并按需上传照片。首次运行的菜单为空。
4. 在「点餐二维码」选择电脑的局域网地址，下载二维码。手机和电脑接入能相互访问的同一网络后即可扫码。
5. 顾客选餐、填写备注并确认模拟支付。取餐号按北京时间每天从 001 起递增，已有号码继续使用，新订单分配时跳过当天已发出的号码。商家进入「取餐订单」，按同号制作单备餐，再点击「出餐就绪」和「确认取餐」。

演示服务需要在扫码期间保持运行。校园网、访客网或 Windows 防火墙可能阻止设备互访。若手机无法打开，换用允许设备互访的 Wi-Fi 或热点，再从商家后台下载新地址对应的二维码。

登录商家后台后，可在侧栏点击「重置密码」，输入当前密码和两遍新密码。保存后需要重新登录。

## 数据与配置

| 配置 | 用途 |
| --- | --- |
| `PORT` | 默认 8787。 |
| `HOST` | 默认 `0.0.0.0`，供局域网访问。设为 `127.0.0.1` 时仅本机访问。 |
| `DATA_DIR` | 默认 `runtime/data`。商家账号、门店、菜单、订单、模拟打印任务和图片保存在此目录，重启可继续使用。 |
| `PUBLIC_BASE_URL` | 反向代理部署后填写公开站点根地址，如 `https://order.example.com`。点餐码优先使用该地址，HTTPS 地址会开启安全 Cookie。 |

同一个数据目录由一个服务进程使用。旧版 Demo 升级后，菜单和订单继续使用，商家从本机入口完成一次手机号注册。备份时保存整个数据目录，团队分享源码时使用源码压缩包。

本次交付运行模拟支付和模拟出票。实际部署时使用 HTTPS，并接入商户支付与打印厂商接口。联调地址、请求格式和适配入口见 [接口说明](docs/API.md)。
